## About Me

I lead a software development team at [CrossRealms International](https://crossrealms.com/), where we build the software behind the company's security services: APIs, automation, integrations, data pipelines and AI-assisted tooling, running across multiple client environments.

I started in the SOC, triaging alerts and supporting customers, before moving into development. That order matters. I have been the person on the receiving end of the tools, so I write software that is safe to run unattended, easy to audit, and clear about what it did and why.

My background is in Mechatronics Engineering, so I came to software through embedded C and control systems. I still think about most problems as a feedback loop: measure, decide, act, check.
